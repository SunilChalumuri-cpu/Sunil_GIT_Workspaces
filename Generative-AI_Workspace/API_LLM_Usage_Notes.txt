4) hit the chat LLM with url having your question
curl -X POST "http://185.216.20.22:8000/v1/chat/completions" \
-H "Content-Type: application/json" \
-H "Authorization: Bearer not-needed" \
-d '{
"model": "openai/gpt-oss-20b",
"messages": [
{"role": "user", "content": "Explain quantum mechanics"}
],
"max_tokens": 20000
}'

PythonCode to call the API of apenAI:
---------------------------------------------
import openai
openai.api_base = "http://185.216.20.22:8000/v1"
openai.api_key = "not-needed"
res = openai.ChatCompletion.create(
model="openai/gpt-oss-20b",
messages=[{"role": "user", "content": "Explain quantum mechanics"}],
stream=True
)
for chunk in res:
    print(chunk.choices[0].delta.get("content", ""), end="", flush=True)
